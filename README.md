# 🌦️ Weather Data Analysis using Python

## 📌 Project Overview
This project focuses on analyzing a real-world weather dataset using Python and Pandas. The dataset contains hourly weather observations including temperature, humidity, wind speed, visibility, pressure, and weather conditions.

The main objective is to explore, clean, and analyze the dataset to extract meaningful insights.

---

## 🎯 Objectives
- Understand the structure of weather data
- Perform data cleaning and preprocessing
- Analyze weather conditions using Pandas
- Answer real-world analytical questions
- Apply filtering, grouping, and aggregation techniques

---

## 📂 Dataset
The dataset contains time-series weather data with the following features:

- Date/Time
- Temperature
- Dew Point Temperature
- Relative Humidity
- Wind Speed
- Visibility
- Pressure
- Weather Condition

---

## 🛠️ Technologies Used
- Python 
- Pandas
- NumPy
- Google Colab

---

## 🔍 Key Operations Performed

### ✔️ Data Exploration
- Display dataset information
- Check data types
- Identify missing values

### ✔️ Data Cleaning
- Convert Date/Time to datetime format
- Handle missing/null values

### ✔️ Data Analysis
- Group data by weather condition
- Calculate mean, min, max values
- Filter specific weather conditions

### ✔️ Sample Queries Solved
- Find all instances of snow weather
- Calculate mean visibility for each weather condition
- Find maximum wind speed
- Filter records with clear weather or high visibility
